ビルクリーニング基礎級 予想問題 自動生成ツール - つかいかた
================================================================

■ これは なに？
  「予想問題を作る.bat」を ダブルクリックする たびに、
  過去問と おなじ けいしきの ○×もんだいを ランダムに くみあわせて、
  あたらしい 問題セット（既定25問）を つくり、ブラウザで ひらきます。

  インターネット接続や API キーは いっさい つかいません。
  すべて この パソコンの なかだけで うごく、オフラインの ツールです。

■ つかいかた（かんたん）
  1. 「予想問題を作る.bat」を ダブルクリックする
  2. すこし まってから、ブラウザに もんだいが ひょうじされる
  3. ○/× を おして こたえると、その ばで せいごたえと かいせつが でます
  4. もう いちど あたらしい 問題を つくりたい ときは、
     もういちど「予想問題を作る.bat」を ダブルクリックする
     （ファイルは 上書きされます）

■ もんだいの しゅるい
  ・どうぐ の もくてき（例：じざいぼうきは 何をする どうぐか）
  ・せんざい の せいしつ（例：尿石は 酸性/アルカリ性/中性の どれで おとすか）
  ・マナー・あんぜん・えいせい に かんする ○×問題

  これらを ランダムに くみあわせる ため、毎回 ちがう 組み合わせの
  問題セットが できます。

■ こまかい せっていを したい とき（Python が わかる人むけ）
  コマンドプロンプトで、この フォルダーに いどうしてから：

    python generate_yosou_mondai.py --count 30
        → 問題数を 30問に する

    python generate_yosou_mondai.py --count 20 --seed 42
        → シード番号を 指定すると、同じ 問題セットを 再現できる

    python generate_yosou_mondai.py --count 20 --txt
        → HTML に くわえて テキスト版（答え・解説つき）も 出力する

■ ちゅうい
  ・生成される 問題は AI が 過去問を もとに 作った「予想問題」であり、
    公式の 過去問そのものでは ありません。
  ・もんだいや 解説の ないように あきたら、
    generate_yosou_mondai.py の 中の TOOLS / DIRTS / STATIC_FACTS の
    リストに 新しい 項目を 追加すると、出題の はばが ひろがります
    （ひらがなで、単語ごとに スペースを あけて 書いてください）。

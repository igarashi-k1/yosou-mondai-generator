# ビルクリーニング技能検定 基礎級 - 予想問題 自動生成ツール

過去問（○×形式・全75問）の出題パターンをもとに、道具の用途・洗剤の性質・マナー/安全衛生の
知識をルールベースで組み合わせて、オリジナルの予想問題をランダムに自動生成するローカルツールです。

**このリポジトリには公式の過去問そのもの（PDF）は含まれていません。**
含まれているのは、独自に作成した知識データベースと生成ロジックのみです。

## 特徴

- インターネット接続・API キー不要のオフラインツール
- 実行するたびに、道具×用途・洗剤×汚れの種類・マナー/安全の正誤ペアを
  ランダムに組み合わせて新しい問題セットを生成
- 生成結果はそのままブラウザで開けるインタラクティブな HTML クイズ
  （○×回答→即座に正誤判定＋解説を表示）
- ひらがな文をローマ字に自動変換する簡易 Hepburn 変換ロジックを内蔵しているため、
  知識データベースに新しい項目を追加してもローマ字を手書きする必要がない

## つかいかた

Windows で `予想問題を作る.bat` をダブルクリックすると、既定25問の問題セットを
生成してブラウザで自動的に開きます。

コマンドラインから直接実行する場合：

```
python generate_yosou_mondai.py --count 25
python generate_yosou_mondai.py --count 30 --seed 42   # シード指定で再現可能
python generate_yosou_mondai.py --count 20 --txt       # テキスト版（解答・解説つき）も出力
```

詳しくは [予想問題ツール_つかいかた.txt](予想問題ツール_つかいかた.txt) を参照してください。

## 知識データベースの拡張

`generate_yosou_mondai.py` 内の `TOOLS` / `DIRTS` / `STATIC_FACTS` のリストに
項目を追加すると、出題の幅が広がります。文はすべてひらがな・単語ごとに
スペース区切りで記述してください（ローマ字は自動生成されます）。

## 免責事項

生成される問題は AI が作成した非公式の予想問題であり、公式の検定試験の内容を
保証するものではありません。
